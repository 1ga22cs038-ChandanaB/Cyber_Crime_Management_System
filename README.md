
# Cyber Crime Reporting System

The Cyber Crime Reporting System is a desktop-based application developed to simplify the process of reporting and tracking cyber crime complaints.

## 🚀 Features
- User Registration & Login Authentication
- File Cyber Crime Complaints
- Unique Complaint ID Generation
- Track Complaint Status
- View Complaint Details
- Refresh Complaint Data (Admin View)

## 🛠️ Technologies Used
- Java (Swing for GUI)
- MongoDB (Database)
- Maven (Project Management)

## 📂 Modules
1. User Module
   - Register
   - Login
   - File Complaint
   - Track Complaint

2. Admin Module (Planned/Future Scope)
   - View Complaints
   - Update Complaint Status

## 💡 How It Works
- Users register and log in to the system.
- They can file complaints by providing details.
- A unique complaint ID is generated.
- Complaint data is stored in MongoDB.
- Users can track complaint status using the ID.

## 📌 Future Enhancements
- Admin Dashboard
- Email Notifications
- Evidence Upload (Images/Documents)
- Integration with real cyber crime portals
